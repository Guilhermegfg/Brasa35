# BRASA 35 — Cardápio Digital

Projeto fictício de demonstração de uma hamburgueria artesanal, desenvolvido com foco em conversão, experiência mobile e pedido direto pelo WhatsApp.

## Funcionalidades

- Cardápio digital responsivo
- Filtros por categoria
- Busca de produtos
- Modal de produto
- Adicionais
- Controle de quantidade
- Carrinho
- Observações do pedido
- Envio do pedido formatado pelo WhatsApp
- Integração com Instagram
- Integração com Google Maps
- SEO local básico
- Design mobile-first

## Tecnologias

- HTML5
- CSS3
- JavaScript puro
